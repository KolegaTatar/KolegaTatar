### 👨‍💻 O mnie

Jestem programistą z komercyjnym doświadczeniem, założycielem marki **[KolegaKoduje.pl](https://kolegakoduje.pl)**. Specjalizuję się w tworzeniu nowoczesnych aplikacji webowych (React, Next.js, TypeScript), wydajnych aplikacji mobilnych (React Native / Expo / Android Java) oraz dedykowanych systemów B2B.

Równolegle rozwijam pasję do sprzętu jako student **Automatyki i Robotyki na Politechnice Poznańskiej**, łącząc oprogramowanie z IoT, sterownikami i mikrokontrolerami (ESP32 / Arduino C++).
